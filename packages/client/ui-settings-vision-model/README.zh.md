# `@deepseek-ai/dsh-client-ui-settings-vision-model`

[English](README.md) | 中文

浏览器插件：注册"识图模型"设置页——一个 provider/model 对，用于路由携带图片的请求，基于 `vision-model` 设置命名空间与无会话模型目录（`llm.models`）。页面只列出声明了图片输入模态的模型；手工输入且未声明能力的模型在此不可见，与路由门禁的处理一致（未声明即为纯文本）。写入以最小 `settings.mutate` 路径操作并携带命名空间修订号落盘，因此并发修改会大声失败而非静默覆盖。

页面在打开时加载，并在推送失效（设置或提供方拓扑变化）时刷新。未配置时说明路由行为；已配置状态显示已存路由与"清除"操作，清除后恢复空的组合基座。

宿主侧为 `@deepseek-ai/dsh-llm-vision-route`；本页面只编辑其拥有的命名空间。

## 模型体验

无；本页面渲染浏览器配置界面，其配置的路由由 `@deepseek-ai/dsh-llm-vision-route` 拥有。

#### KV 缓存影响

无；本包既不组装也不发送提供方请求。

## 已知限制与待办

- **单一路由而非列表**——页面只保存一个 provider/model 对；按会话的识图覆盖不在范围内。
- **目录仅作参考**——模型来自实时 `llm.models` 目录；停止宣传某模型的路由仍可工作，但会从页面消失。
